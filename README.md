# create.website

אתר תדמית בעברית וב־RTL ליצירת אתרים מתוך תבניות מוכנות.

## מה יש כאן

- גלריית תבניות: סטודיו קריאייטיב, חנות אונליין, עסק קטן ופורטפוליו.
- בחירת תבנית פותחת טופס יצירה אינטראקטיבי.
- עיצוב רספונסיבי למובייל ולדסקטופ.
- קישורים ל־TikTok: [@create_website](https://www.tiktok.com/@create_website).
- מוכן לפרסום כ־GitHub Pages — ללא build וללא תלויות.

## הפעלה מקומית

```bash
python3 -m http.server 4173
```

ואז לפתוח: <http://localhost:4173>

## פרסום ב־GitHub Pages

ב־GitHub: **Settings → Pages → Deploy from a branch → main → / (root)**.
