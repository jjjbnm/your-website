# אתר יצירת האתרים של אוראל

אתר RTL בעברית, בקובץ HTML יחיד, עם:

- בחירת נושא מתוך מאות אפשרויות.
- חיפוש חכם וסינון לפי קטגוריות.
- טופס פרטים מורחב.
- יצירת הודעת WhatsApp מוכנה למספר שהוגדר בקוד.
- כפתור מייל שמוגן עד שמכניסים כתובת אמיתית.
- עיצוב רספונסיבי עם רקע זכוכית ואנימציות.

## הפעלה מקומית

```bash
python3 -m http.server 4173
```
